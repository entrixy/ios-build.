# Entrixy: установка на iPhone 11 с Windows 11

Это отдельная версия для бесплатной личной подписи. Основное приложение требует
iOS16 или новее. Своего Mac и платного Apple Developer Program для этого способа
не требуется. Файл IPA содержит настоящее arm64 приложение для физического
iPhone; до установки оно не подписано вашим Apple Account.

## Подготовка

1. Скачайте `Entrixy-iPhone11.ipa` из выданного пакета. Хеш находится в
   `SHA256SUMS`, сведения об исходнике и сборке — в `package.json`.
2. На телефоне откройте «Настройки → Основные → Об этом устройстве» и посмотрите
   версию iOS. Если она ниже16, текущая сборка на ней не установится.
3. Установите Sideloadly для Windows с https://sideloadly.io/. Используйте только
   официальный сайт. Там же в блоке Before you install скачайте версии iTunes
   и iCloud с сайта Apple: Sideloadly требует их вместо версий из Microsoft Store.
   Не включайте внедрение библиотек, изменение версии iOS или
   обход проверок совместимости — приложение собрано под физический iPhone.
4. Подготовьте USB-кабель с передачей данных. Подключите разблокированный телефон
   к компьютеру и подтвердите доверие компьютеру. Если установщик не видит
   телефон, воспользуйтесь инструкцией по драйверам/iTunes на официальном сайте
   Sideloadly: https://sideloadly.io/faq.html.

## Подпись и установка

1. Откройте Sideloadly, выберите iPhone и перетащите IPA в окно программы.
2. Введите свой Apple Account в установщике и нажмите Start. Пароль и коды
   подтверждения вводите самостоятельно в программе; отправлять их агенту не нужно.
3. Если iOS требует доверия разработчику: «Настройки → Основные → VPN и управление
   устройством» → ваш профиль → доверять. Если требуется режим разработчика:
   «Настройки → Конфиденциальность и безопасность → Режим разработчика» → включить;
   выполните предложенную телефоном перезагрузку и подтверждение.
4. Запустите Entrixy. Разрешения Bluetooth, геолокации, камеры и уведомлений
   предоставляйте для тех функций, которые собираетесь проверять.

Бесплатная подпись действует7дней. Для обновления устанавливайте новую IPA поверх
старой с тем же Apple Account и тем же идентификатором приложения. Не удаляйте
Entrixy ради обновления: сначала сохраните зашифрованную резервную копию доступов.
Не меняйте вручную Bundle ID между установками — это может изменить доступ к
Keychain. Системное поведение и установка на вашем телефоне проверяются отдельно.

## Какие функции входят в эту версию

Версия включает обычные пути приложения: импорт ключей/резервных копий, подключение
к серверу, объекты, гостевые доступы/передачи, сообщения в активном приложении,
журнал, камера, защищённое ручное Bluetooth-управление и доступные системе
сценарии автоматики. Реальная работа с вашим контроллером/камерой и версия iOS
принимаются на телефоне, а не по наличию файла IPA.

Бесплатный профиль не включает APNs, виджет/App Group, Associated Domains и
Access Wi-Fi Information. Локальные уведомления и импорт ссылки внутри приложения
остаются отдельными механизмами. Правила доступа не отключены: объект с
обязательной неподтверждённой Wi-Fi-проверкой не должен открываться в обход неё.
Эта версия не заменяет подписанный выпуск для App Store/TestFlight.
